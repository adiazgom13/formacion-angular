# Frontend routes

Routes are declared in `src/app/app.routes.ts`.

| Path | Component |
|------|-----------|
| `/login` | `LoginComponent` |
| `/home` | `HomeComponent` |
| `/catalogue` | `CatalogueComponent` |
| `/brands` | `BrandsComponent` |
| `/car/:id` | `CarComponent` |
| `/` | redirect to `/home` |
| `/**` | redirect to `/home` |
